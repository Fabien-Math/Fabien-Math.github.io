| Fonction       | Exemple              | Description                                  |
| -------------- | -------------------- | -------------------------------------------- |
| `print()`      | `print("Hello")`     | Affiche une valeur                           |
| `input()`      | `input("Nom : ")`    | Lit une saisie utilisateur                   |
| `type()`       | `type(x)`            | Retourne le type d'un objet                  |
| `isinstance()` | `isinstance(x, int)` | Vérifie le type d'un objet                   |
| `len()`        | `len([1, 2, 3])`     | Retourne la longueur                         |
| `range()`      | `range(10)`          | Génère une séquence d'entiers                |
| `enumerate()`  | `enumerate(values)`  | Parcourt une collection avec son index       |
| `zip()`        | `zip(a, b)`          | Parcourt plusieurs collections simultanément |
| `sorted()`     | `sorted(values)`     | Retourne une collection triée                |
| `reversed()`   | `reversed(values)`   | Retourne une séquence inversée               |
| `min()`        | `min(values)`        | Retourne la valeur minimale                  |
| `max()`        | `max(values)`        | Retourne la valeur maximale                  |
| `sum()`        | `sum(values)`        | Calcule la somme                             |
| `abs()`        | `abs(-5)`            | Valeur absolue                               |
| `round()`      | `round(3.14159, 2)`  | Arrondit un nombre                           |
| `pow()`        | `pow(2, 3)`          | Calcule une puissance                        |
| `divmod()`     | `divmod(10, 3)`      | Retourne quotient et reste                   |
| `int()`        | `int("42")`          | Convertit en entier                          |
| `float()`      | `float("3.14")`      | Convertit en réel                            |
| `str()`        | `str(42)`            | Convertit en chaîne                          |
| `bool()`       | `bool(1)`            | Convertit en booléen                         |
| `list()`       | `list(range(5))`     | Crée une liste                               |
| `tuple()`      | `tuple([1, 2, 3])`   | Crée un tuple                                |
| `set()`        | `set([1, 2, 2, 3])`  | Crée un ensemble                             |
| `dict()`       | `dict(a=1, b=2)`     | Crée un dictionnaire                         |
| `any()`        | `any([False, True])` | `True` si au moins un élément est vrai       |
| `all()`        | `all([True, True])`  | `True` si tous les éléments sont vrais       |
| `dir()`        | `dir(obj)`           | Liste les attributs et méthodes              |
| `help()`       | `help(print)`        | Affiche la documentation                     |
| `id()`         | `id(obj)`            | Retourne l'identifiant de l'objet            |
| `open()`       | `open("data.txt")`   | Ouvre un fichier                             |
| `eval()`       | `eval("2 + 3")`      | Évalue une expression Python                 |
| `exec()`       | `exec(code)`         | Exécute du code Python                       |
