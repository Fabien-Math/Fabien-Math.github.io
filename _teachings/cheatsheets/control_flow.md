| Structure | Syntaxe           | Utilisation                                                 |
| --------- | ----------------- | ----------------------------------------------------------- |
| `if`      | `if condition:`   | Exécuter du code si une condition est vraie                 |
| `elif`    | `elif condition:` | Tester une condition supplémentaire                         |
| `else`    | `else:`           | Exécuter du code si aucune condition précédente n'est vraie |


| Structure  | Syntaxe              | Utilisation                                |
| ---------- | -------------------- | ------------------------------------------ |
| `for`      | `for x in iterable:` | Répéter pour chaque élément d'une séquence |
| `while`    | `while condition:`   | Répéter tant qu'une condition est vraie    |
| `break`    | `break`              | Sortir immédiatement d'une boucle          |
| `continue` | `continue`           | Passer directement à l'itération suivante  |
| `pass`     | `pass`               | Ne rien faire                              |

| Structure | Syntaxe         | Utilisation                                    |
| --------- | --------------- | ---------------------------------------------- |
| `match`   | `match value:`  | Effectuer un choix selon la valeur / structure |
| `case`    | `case pattern:` | Définir un cas dans un `match`                 |

| Structure | Syntaxe             | Utilisation                                             |
| --------- | ------------------- | ------------------------------------------------------- |
| `try`     | `try:`              | Exécuter du code susceptible de provoquer une exception |
| `except`  | `except Exception:` | Gérer une exception                                     |
| `else`    | `else:`             | Exécuter du code si aucune exception n'a été levée      |
| `finally` | `finally:`          | Exécuter du code dans tous les cas                      |
