| Catégorie     | Nom en français           | Mots-clés Python                   | Rôle                                              |
| ------------- | ------------------------- | ---------------------------------- | ------------------------------------------------- |
| Conditions    | Structure conditionnelle  | `if`, `elif`, `else`               | Exécuter du code selon une condition              |
| Boucles       | Structure répétitive      | `for`, `while`                     | Répéter du code                                   |
| Boucles       | Contrôle de boucle        | `break`, `continue`                | Modifier le comportement d'une boucle             |
| Contrôle      | Instruction vide          | `pass`                             | Ne rien exécuter                                  |
| Sélection     | Sélection par motifs      | `match`, `case`                    | Choisir un bloc selon une valeur ou un motif      |
| Exceptions    | Gestion des exceptions    | `try`, `except`, `else`, `finally` | Gérer les erreurs                                 |
| Exceptions    | Levée d'exception         | `raise`                            | Déclencher une exception                          |
| Fonctions     | Définition de fonction    | `def`                              | Définir une fonction                              |
| Fonctions     | Retour de fonction        | `return`                           | Renvoyer une valeur                               |
| Fonctions     | Fonction anonyme          | `lambda`                           | Créer une fonction courte                         |
| Classes       | Définition de classe      | `class`                            | Définir une classe                                |
| Modules       | Importation               | `import`, `from`, `as`             | Importer du code externe                          |
| Variables     | Suppression               | `del`                              | Supprimer une référence ou un élément             |
| Logique       | Valeur logique            | `True`, `False`                    | Représenter vrai / faux                           |
| Null          | Absence de valeur         | `None`                             | Représenter l'absence de valeur                   |
| Logique       | Opérateurs logiques       | `and`, `or`, `not`                 | Combiner ou inverser des conditions               |
| Appartenance  | Opérateurs d'appartenance | `in`, `not in`                     | Tester la présence d'un élément                   |
| Identité      | Opérateurs d'identité     | `is`, `is not`                     | Tester si deux références désignent le même objet |
| Contexte      | Gestionnaire de contexte  | `with`                             | Gérer automatiquement une ressource               |
| Contexte      | Création d'un générateur  | `yield`                            | Produire une valeur progressivement               |
| Asynchrone    | Fonction asynchrone       | `async`, `await`                   | Programmer de manière asynchrone                  |
| Portée        | Variable non locale       | `global`, `nonlocal`               | Modifier la portée d'une variable                 |
| Assertions    | Vérification              | `assert`                           | Vérifier une condition                            |
| Documentation | Documentation             | `__doc__`                          | Accéder à la documentation d'un objet             |
